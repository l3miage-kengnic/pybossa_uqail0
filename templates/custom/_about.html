{{ _('About') }} {{ brand }}

{{ _('%(brand)s stands for User Quality Assessment of Intelligent Logic. It is an annotation platform where domain experts judge the answers, and the reasoning behind them, that AI systems produce from biomedical knowledge graphs.', brand=brand) }}

{{ _('Why') }}

{{ _('Knowledge-graph question answering systems can return a plausible answer together with a chain of facts that supposedly justifies it. Whether that chain is correct, relevant and well sourced cannot be judged by machines alone. %(brand)s collects structured expert judgements on these answers so that systems can be compared and improved on solid ground.', brand=brand) }}

{{ _('How a campaign works') }}

  • {{ _('The research team selects question/answer items and defines a campaign: how many experts judge each item, which items are shared by everyone, and how many control items are inserted.') }}
  • {{ _('Each invited annotator receives a personal queue. The model that produced an answer is never shown: judgements are blind.') }}
  • {{ _('For every item the annotator scores the reasoning, the sources and the final result, and can leave a comment. Start and end times and the interface version are recorded.') }}
  • {{ _('Judgements are collected by the research team, checked against control items, and analysed for inter-annotator agreement. Campaign plans are generated from a fixed seed and can be replayed identically.') }}
